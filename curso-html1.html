Introdução ao HTML

HTML significa HyperText Markup Language. Ele é a linguagem responsável por estruturar o conteúdo de um site — textos, imagens, links, vídeos, tabelas e muito mais.

O que é HTML?

HTML é uma linguagem de marcação, não uma linguagem de programação. Isso significa que o HTML serve para marcar e organizar os elementos da página.

<html>
  <head>
    <title>Meu Site</title>
  </head>

  <body>
    <h1>Bem-vindo!</h1>
    <p>Este é meu primeiro parágrafo.</p>
  </body>
</html>

Como o HTML funciona?

O HTML utiliza estruturas chamadas tags. Essas tags dizem ao navegador como exibir cada parte do conteúdo.

<h1>Título Grande</h1>
<p>Isso é um parágrafo.</p>
💡 Dica: A maioria das tags possui abertura <tag> e fechamento </tag>.

Estrutura Básica de Uma Página HTML

Todo arquivo HTML começa com uma estrutura padrão:

<!DOCTYPE html>
<html lang="pt-br">
  <head>
    <meta charset="UTF-8">
    <title>Exemplo</title>
  </head>

  <body>
    <h1>Olá!</h1>
  </body>
</html>
  • <html> → envolve toda a página
  • <head> → configurações, título, links
  • <body> → conteúdo visível do site

Exemplo de Página Completa

Aqui está um exemplo simples de página:

<html>
<body>
<h1>Bem-vindo ao Byte&Byte!</h1>
<p>Estamos aprendendo HTML do zero!v/p>
</body>
</html>
