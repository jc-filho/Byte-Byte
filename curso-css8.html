Responsividade no CSS

A responsividade é uma técnica fundamental no desenvolvimento web moderno. Ela permite que o site se adapte automaticamente a diferentes tamanhos de tela, como celulares, tablets, notebooks e TVs.

📌 O que é Responsividade?

Responsividade é a capacidade de um site ajustar seu layout, tamanho dos elementos e estrutura de acordo com o dispositivo usado pelo usuário.

💡 Dica: Sites responsivos tornam a navegação mais confortável e melhoram a experiência do usuário.

1️⃣ Meta Viewport

O primeiro passo para responsividade é garantir que o navegador interprete corretamente o tamanho da tela.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Sem isso, a página “explode” no celular, aparecendo gigante e difícil de navegar.

2️⃣ Unidades Flexíveis

Para adaptar o tamanho dos elementos, utilizamos unidades como:

  • % — porcentagem da largura disponível
  • vh / vW — altura/largura da tela
  • rem / em — tamanhos relativos à fonte
  • auto — ajusta sozinho
.imagem { width: 100%; max-width: 400px; }

3️⃣ Media Queries

Media Queries são regras especiais do CSS que mudam o layout conforme o tamanho da tela.

@media (max-width: 768px) { .container { flex-direction: column; } nav ul { flex-direction: column; } }

📌 Isso significa: “Quando a tela tiver MENOS que 768px, mude o estilo”.

4️⃣ Layouts Fluídos

Em vez de usar larguras fixas (como 1200px), usamos valores que se ajustam:

.conteudo { width: 90%; margin: auto; }

5️⃣ Imagens Responsivas

img { width: 100%; height: auto; }

Isso evita que imagens transbordem para fora da tela do celular.

6️⃣ Menu Responsivo

O menu geralmente vira um “menu hambúrguer” no celular.

@media (max-width: 768px) { nav ul { display: none; } .menu-icon { display: block; } }

7️⃣ Grid Responsivo

.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); }

O auto-fit cria colunas automaticamente conforme o tamanho disponível.

🎯 Desafios Comuns

  • Fontes muito pequenas no celular
  • Imagens estourando
  • Botões pequenos demais
  • Elementos sobrepostos

🎓 Exercício Prático

Crie uma página com:

  • Um cabeçalho
  • Um menu responsivo
  • Uma imagem grande responsiva
  • Um texto dividido em 2 colunas no PC e 1 coluna no celular

Use media queries para ajustar o layout!
