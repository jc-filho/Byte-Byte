📦 O que são Variáveis?

Variáveis são como “caixas” que armazenam valores para serem usados e modificados durante a execução de um programa.

Variáveis

Uma variável é um espaço reservado na memória do computador para guardar dados que podem ser alterados ao longo do programa.

💡 Pense assim: uma variável é como uma **caixa com um nome**. Você coloca algo dentro dela (um número, um texto) e pode trocar o conteúdo quando quiser.

Tipos de Dados

As variáveis podem armazenar diferentes tipos de valores. Os principais são:

1. Números Inteiros

Usados para valores sem casas decimais.

idade = 25 ano = 2024 quantidade = 100

2. Números Decimais

Usados para valores com vírgula (ponto no computador).

altura = 1.75 peso = 70.5 preco = 29.99

3. Texto (String)

Usados para armazenar frases ou palavras.

nome = "Maria Silva" cidade = "Mossoró" mensagem = "Bem-vindo ao curso!"

4. Valores Lógicos (Booleanos)

Usados para armazenar apenas dois valores: verdadeiro ou falso.

aprovado = VERDADEIRO chovendo = FALSO maiorDeIdade = VERDADEIRO

Como Declarar e Usar Variáveis

Veja um exemplo em pseudocódigo:

ALGORITMO "Exemplo de Variáveis" INÍCIO // Declaração INTEIRO idade REAL salario TEXTO nome LOGICO trabalhando // Atribuição de valores idade <- 30 salario <- 5000.00 nome <- "Maria" trabalhando <- VERDADEIRO // Uso das variáveis ESCREVER "Nome: " , nome ESCREVER "Idade: " , idade, " anos" ESCREVER "Salário: R$ " , salario FIM
📌 Regras para nomes de variáveis:
  • Devem começar com uma letra
  • Não podem ter espaços ou acentos
  • Não podem ser palavras reservadas da linguagem
  • Use nomes descritivos para facilitar a leitura
