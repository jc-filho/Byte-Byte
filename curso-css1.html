Introdução ao CSS

CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas HTML. Com ele você controla cores, tamanhos, posicionamento, fontes, espaçamentos e praticamente tudo o que define o visual de um site moderno.

O que é CSS?

CSS é uma linguagem que define a aparência dos elementos HTML. O HTML cria a estrutura, enquanto o CSS deixa tudo bonito, organizado e profissional.

h1 { color: orange; font-size: 30px; text-align: center; }

Como usar o CSS?

Existem 3 formas principais de usar CSS em uma página:

1. CSS Inline

<h1 style="color: orange;">Título</h1>

2. CSS Interno

<style> p { color: #d35400; } </style>

3. CSS Externo (o MAIS usado)

<link rel="stylesheet" href="style.css">
💡 Dica: Sempre prefira CSS externo! Mantém tudo organizado.

Sintaxe do CSS

A estrutura básica do CSS é composta por:

  • Seletor — quem você quer estilizar;
  • Propriedade — o que você quer alterar;
  • Valor — como você quer alterar;
seletor { propriedade: valor; }

Principais Seletores

Seletor por Tag

p { color: orange; }

Seletor por Classe

.botao { background: #e67e22; }

Seletor por ID

#titulo { font-size: 40px; }

Seletor Universal

* { margin: 0; padding: 0; }

🎯 Exercício

Crie um estilo que deixe todos os parágrafos com texto laranja e tamanho 18px.

Cores no CSS

Formas de definir cores:

  • Nome: orange
  • Hexadecimal: #e67e22
  • RGB: rgb(230, 126, 34)
  • HSL: hsl(28, 80%, 52%)
  • Gradientes
background: linear-gradient(to right, #e67e22, #d35400);

Unidades Mais Usadas

  • px – tamanho fixo
  • % – relativo ao elemento pai
  • em / rem – relativo ao tamanho da fonte
  • vh / vw – relativo à tela

Box Model (muito importante!)

Todo elemento HTML é uma caixa composta por:

  • Content – o conteúdo
  • Padding – espaço interno
  • Border – borda do elemento
  • Margin – espaçamento externo
div { margin: 20px; padding: 15px; border: 2px solid #e67e22; }

Principais Propriedades do CSS

  • color
  • background
  • font-size
  • margin
  • padding
  • border
  • width / height
  • display
  • flex
  • position
