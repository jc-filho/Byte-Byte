📜 Vamos aprender sobre Algoritmos!

Um algoritmo é uma sequência de passos bem definidos que resolvem um problema. É a base da lógica de programação!

O que é um Algoritmo?

Um algoritmo é um conjunto finito de instruções que, quando executadas em ordem, resolvem um problema ou realizam uma tarefa.

💡 Pense assim: Um algoritmo é como uma receita de bolo. Se você seguir todos os passos corretamente, vai ter o resultado esperado!

Características de um Bom Algoritmo

  • Clareza: deve ser fácil de entender
  • Precisão: cada passo é bem definido
  • Eficiência: deve ser o mais simples possível
  • Finitude: sempre termina após um número finito de passos

Exemplo do Dia a Dia

Exemplo de algoritmo para escovar os dentes:

1. Pegar a escova 2. Colocar pasta de dente 3. Escovar os dentes por 2 minutos 4. Enxaguar a boca 5. Guardar a escova

Formas de Representar Algoritmos

1. Linguagem Natural

Usa frases do dia a dia para descrever os passos:

Algoritmo para trocar uma lâmpada: 1. Desligar o interruptor 2. Pegar uma escada 3. Subir na escada 4. Desenroscar a lâmpada queimada 5. Colocar a nova lâmpada 6. Descer da escada 7. Ligar o interruptor

2. Pseudocódigo

Uma forma próxima de código, mas ainda fácil de entender:

ALGORITMO "Calcular Média" INÍCIO ESCREVER "Digite a primeira nota: " LER nota1 ESCREVER "Digite a segunda nota: " LER nota2 media <- (nota1 + nota2) / 2 SE media>= 7 ENTÃO ESCREVER "Aprovado! Média: ", media SENÃO ESCREVER "Reprovado! Média: ", media FIM SE FIM

3. Fluxograma

Representa o algoritmo de forma visual com símbolos e setas (iremos ver mais sobre isso em outra aula!).

🎯 Exercício Prático

Escreva um algoritmo em linguagem natural para preparar um café. Liste os passos em ordem lógica.
