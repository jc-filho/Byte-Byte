Seletores e Propriedades do CSS

Em CSS, os seletores definem quais elementos do HTML serão estilizados e as propriedades especificam o estilo aplicado. Entender bem esses dois conceitos é essencial para dominar o CSS.

O que são Seletores?

Seletores são “endereços” usados para selecionar elementos HTML e aplicar estilos. Cada seletor possui um propósito diferente.

h1 { color: blue; } .titulo { font-size: 30px; } #principal { background: yellow; }

Tipos de Seletores

1️⃣ Seletor por Tag

Seleciona todos os elementos de uma determinada tag.

p { color: #333; line-height: 1.5; }

2️⃣ Seletor por Classe

A classe é usada para agrupar elementos com estilos iguais.

.caixa { background: #ffe9c6; padding: 20px; border-radius: 10px; }

3️⃣ Seletor por ID

Usado para identificar um elemento único.

#menu { background: #ffb347; }

4️⃣ Seletores Universais

Seleciona todos os elementos da página.

* { margin: 0; padding: 0; }

5️⃣ Seletores de Atributos

Seleciona elementos com atributos específicos.

input[type="text"] { border: 2px solid orange; } a[target="_blank"] { color: green; }

6️⃣ Seletor Descendente

Aplica estilo a elementos DENTRO de outros.

div p { color: orange; }

7️⃣ Seletor Filho Direto

Seleciona apenas filhos DIRETOS.

ul > li { color: brown; }

8️⃣ Seletor de Estado (Pseudo-classes)

a:hover { color: red; text-decoration: underline; } input:focus { border-color: orange; }

9️⃣ Pseudo-elementos

p::first-letter { font-size: 40px; color: orange; } p::before { content: "👉 "; }
💡 Dica: Prefira usar classes ao invés de IDs para estilizar elementos. IDs têm prioridade maior e podem atrapalhar estilos mais complexos.

O que são Propriedades?

As propriedades definem o estilo aplicado ao elemento selecionado.

Exemplos de propriedades importantes:

  • color: cor do texto
  • background: cor de fundo
  • font-size: tamanho da fonte
  • padding: espaço interno
  • margin: espaço externo
  • border: borda do elemento
  • width / height: dimensões
.card { background: #fff6e0; border: 1px solid #ffb347; padding: 20px; margin: 10px; width: 200px; height: 150px; }

🎯 Desafio Prático

Crie um bloco colorido com:

  • Classe chamada .box-laranja
  • Cor de fundo laranja
  • Borda arredondada
  • Texto centralizado
  • Padding de 20px

Depois, crie um seletor :hover mudando a cor ao passar o mouse.
