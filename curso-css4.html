Box Model – Entendendo o Modelo de Caixas do CSS

O Box Model é um dos conceitos mais importantes do CSS. Ele define como **todos os elementos HTML** são representados visualmente na tela: como caixas compostas por content, padding, border e margin.

📦 O que é o Box Model?

Todo elemento HTML é uma caixa, mesmo que você não perceba. Essa caixa é composta por 4 camadas:

CONTENT → O conteúdo (texto, imagem, etc.) PADDING → Espaço interno entre o conteúdo e a borda BORDER → A borda da caixa MARGIN → Espaço externo, separação entre elementos

Camadas do Box Model

1️⃣ Content (Conteúdo)

É aquilo que realmente está dentro da caixa, como textos, imagens ou botões.

div { width: 200px; height: 100px; background-color: #ffa94d; }

2️⃣ Padding (Preenchimento interno)

Cria espaço ENTRE o conteúdo e a borda.

div { padding: 20px; }
💡 Dica: Padding aumenta o tamanho visível da caixa.

3️⃣ Border (Borda)

A borda envolve todo o conteúdo + padding.

div { border: 3px solid #ff7b00; border-radius: 10px; }

4️⃣ Margin (Margem externa)

A margem cria espaço ao redor da caixa, separando-a de outros elementos.

div { margin: 40px; }

📐 Calculando o tamanho total de uma caixa

Por padrão, o navegador calcula o tamanho assim:

Tamanho total horizontal = width + padding-esq + padding-dir + border-esq + border-dir + margin-esq + margin-dir Tamanho total vertical = height + padding-top + padding-bottom + border-top + border-bottom + margin-top + margin-bottom

🔧 Usando box-sizing

O CSS possui a propriedade box-sizing para facilitar a vida:

/* O width NÃO considera padding e borda */ box-sizing: content-box; /* O width JÁ inclui padding e borda */ box-sizing: border-box;
Recomendado: Sempre usar border-box no seu projeto.

Exemplo Completo

.caixa { width: 300px; padding: 20px; border: 4px solid #ff8800; margin: 40px auto; box-sizing: border-box; background-color: #fff4e0; }

Crie 3 caixas diferentes utilizando:

  • bordas arredondadas
  • margens automáticas
  • box-sizing: border-box
