Imagens e Links no HTML

As imagens e os links são fundamentais para a construção de qualquer site. Com eles, você pode criar páginas navegáveis e visuais mais atraentes.

📸 Inserindo Imagens

Para inserir uma imagem no HTML, utilizamos a tag <img>. Ela é uma tag que **não possui fechamento** e precisa de atributos obrigatórios.

<img src="cachorro.jpg" alt="Um cachorro fofo" width="300">

Atributos importantes da tag <img>

  • src: caminho da imagem
  • alt: texto alternativo (acessibilidade e SEO)
  • width / height: largura e altura
  • title: texto quando o cursor passa por cima
💡 Dica: Sempre coloque um alt para descrever a imagem. Isso ajuda deficientes visuais e melhora o SEO do seu site.

🌐 Criando Links

Os links são criados com a tag <a>. Ela leva o usuário para outra página ou site.

<a href="https://www.google.com">Ir para o Google</a>

Atributos principais de <a>

  • href: destino do link
  • target="_blank": abre em nova aba
  • title: texto ao colocar o mouse em cima

🔗 Exemplo com nova aba

<a href="https://youtube.com" target="_blank" title="Abrir YouTube">Visitar YouTube</a>

🖼️ Transformando Imagens em Links

Você também pode transformar uma imagem em um link clicável:

<a href="pagina.html"> <img src="logo.png" alt="Logo"> </a>

💼 Exemplos Práticos

🧩 Banner no topo do site

Use a tag <img> para imagens grandes.

🔗 Menu com ícones

Ícones podem ser imagens com links para páginas internas.

📎 Links de download

Você pode linkar PDFs, arquivos ZIP, docs e muito mais!

🎯 Exercício Prático

Crie uma página contendo:

  • Uma imagem com largura 300px
  • Um link que abre em nova aba
  • Uma imagem que funciona como botão/link
