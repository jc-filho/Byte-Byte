Atributos HTML

Os atributos HTML são informações extras adicionadas dentro das tags para modificar seu comportamento. Eles permitem configurar propriedades como cor, tamanho, identificação, links, acessibilidade e muito mais.

O que são Atributos?

Um atributo é formado por um nome e um valor.

<tag atributo="valor"> Conteúdo </tag>

Atributos Mais Usados no HTML

1. id – Identificar um elemento

Usado para identificar um elemento único na página:

<h1 id="titulo-principal">Bem-vindo!</h1>

2. class – Agrupar elementos

Usado para aplicar o mesmo estilo em vários elementos:

<p class="descricao">Esse é um parágrafo...</p>

3. src – Caminho de arquivos

Usado para carregar imagens, vídeos e scripts:

<img src="img/foto.png" alt="Minha foto">

4. href – Links

Indica o destino de um link:

<a href="https://google.com">Acessar Google</a>

5. alt – Texto alternativo de imagens

Ajuda na acessibilidade e no SEO:

<img src="logo.png" alt="Logo da empresa">

6. title – Texto exibido ao passar o mouse

<p title="Dica!">Passe o mouse aqui!</p>

Atributos Globais

Podem ser usados em qualquer tag HTML:

  • id
  • class
  • style
  • title
  • hidden
  • lang
