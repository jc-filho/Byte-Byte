CSS Grid Layout

O CSS Grid Layout é um dos sistemas mais poderosos do CSS para criar layouts modernos, organizados e totalmente responsivos. Diferente do Flexbox — que organiza elementos em linha — o Grid permite trabalhar com duas dimensões: linhas e colunas.

O que é o CSS Grid?

O Grid funciona como uma espécie de “grade” onde os elementos podem ser posicionados de forma precisa. É ideal quando você precisa de:

  • Layouts de sites completos
  • Áreas complexas de conteúdo
  • Estruturas responsivas controladas
  • Divisão horizontal + vertical ao mesmo tempo
grid-container { display: grid; grid-template-columns: 200px 200px 200px; gap: 20px; } grid-item { background: orange; padding: 20px; color: white; }

Criando um Grid

Para iniciar um grid, basta aplicar a propriedade display: grid; ao elemento pai.

.container { display: grid; }

Definindo Colunas com grid-template-columns

Você pode definir quantas colunas quiser e seus tamanhos:

.container { display: grid; grid-template-columns: 100px 200px 300px; }

Também pode usar a unidade fr (fração da tela):

.container { display: grid; grid-template-columns: 1fr 2fr 1fr; }

Definindo Linhas

.container { display: grid; grid-template-rows: 150px 250px 150px; }

Espaçamento — gap

Muito mais simples que margin:

.container { display: grid; gap: 20px; }

Grid Responsivo com repeat()

.container { display: grid; grid-template-columns: repeat(3, 1fr); }

Grid Automático com auto-fit e minmax()

Essa combinação cria um grid totalmente responsivo:

.container { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; }

Posicionando Itens

Você pode controlar onde cada item fica:

.item1 { grid-column: 1 / 3; grid-row: 1 / 2; }

Grid Áreas — Nomeando Regiões

.container { display: grid; grid-template-areas: "header header" "sidebar content" "footer footer"; grid-template-columns: 200px 1fr; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .content { grid-area: content; } .footer { grid-area: footer; }

Quando usar CSS Grid?

🧱 Layouts completos

Sites inteiros, dashboards, painéis e sistemas.

📐 Estruturas complexas

Múltiplas linhas e colunas com grande controle.

📱 Alta responsividade

Layouts que se ajustam automaticamente.
