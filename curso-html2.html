Tags Básicas do HTML

HTML é a linguagem base da web. Antes de criar sites completos, é essencial conhecer as tags fundamentais que estruturam uma página.

🔸 O que é uma Tag?

Uma tag é um comando utilizado pelo HTML para indicar ao navegador como um conteúdo deve ser exibido.

<tag> Conteúdo </tag>

📌 Principais Tags Iniciais

1. <html>

Define todo o documento HTML:

<html>
  ...conteúdo...
</html>

2. <head>

Guarda informações do site (título, ícone, links de estilo):

<head>
  <title>Meu Site</title>
</head>

3. <body>

É onde fica todo o conteúdo visível:

<body>
  <h1>Olá Mundo!</h1>
</body>

4. <h1> até <h6>

São títulos, indo do maior ao menor:

<h1>Título Principal</h1>
<h2>Subtítulo</h2>

5. <p>

Define parágrafos:

<p>Este é um parágrafo.</p>
💡 Dica: Sempre feche sua tag caso ela tenha fechamento obrigatório.

🎯 Exercício

Crie uma página HTML com:

  • um título <h1>
  • dois parágrafos <p>
  • um subtítulo <h2>
