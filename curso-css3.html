Cores e Unidades no CSS

As cores e unidades são fundamentais para criar estilos mais bonitos, organizados e responsivos no CSS. Nesta aula você aprenderá como definir cores de várias maneiras e como utilizar diferentes unidades de medida.

🎨 Tipos de Cores no CSS

1. Nome das cores

O CSS possui mais de 140 nomes de cores já definidos.

color: orange;
background: tomato;
border-color: gold;

2. Cores Hexadecimais

Formato mais comum: #RRGGBB

color: #ff6600;
background: #f39c12;

3. RGB

color: rgb(255, 100, 0);
background: rgb(255, 150, 70);

4. RGBA (com transparência)

background: rgba(255, 140, 0, 0.5);

5. HSL (Hue, Saturation, Lightness)

É uma forma mais intuitiva de trabalhar com cores.

color: hsl(30, 100%, 50%);
background: hsl(25, 90%, 60%);
💡 Dica: HSL é excelente para criar paletas harmônicas.

📏 Unidades no CSS

No CSS usamos unidades para definir tamanhos, distâncias, espaçamentos e muito mais.

Unidades Absolutas

  • px — pixel
  • cm, mm — centímetros e milímetros
  • in — polegadas
font-size: 18px;
margin: 10px;

Unidades Relativas

  • % — relativo ao elemento pai
  • em — relativo ao font-size do elemento pai
  • rem — relativo ao font-size da raiz
  • vw — porcentagem da largura da tela
  • vh — porcentagem da altura da tela
font-size: 2em;
width: 80%;
height: 50vh;

Comparação entre unidades

⚠️ Importante: sempre que quiser que o layout seja responsivo, prefira %, vw, vh ou rem.

📌 Exercício

Crie uma caixa com:

  • largura em %
  • altura em vh
  • cor de fundo em rgba()
  • título colorido com hsl()
