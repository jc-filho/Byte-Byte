Display & Layout (CSS Clássico)

Antes dos sistemas modernos como Flexbox e Grid, os layouts eram construídos com métodos mais simples (e às vezes mais difíceis). Aqui vamos aprender como funcionavam as versões antigas de layout do CSS, que ainda são úteis para entender o passado e manipular código legado.

1️⃣ display: block

Um elemento block ocupa toda a largura disponível e sempre quebra linha.

div {
  display: block;
}
  • Ocupa 100% da linha
  • Sempre inicia em uma nova linha
  • Permite definir width/height

2️⃣ display: inline

O elemento fica na mesma linha. **Não aceita width e height**.

span {
  display: inline;
}
💡 Dica: inline é indicado para textos, links e ícones pequenos.

3️⃣ display: inline-block

Combina o melhor dos dois mundos: fica na linha, mas aceita width/height.

img {
  display: inline-block;
  width: 200px;
}

4️⃣ O sistema de Layout com Float (CSS Antigo)

Antes do Flexbox, **todas as páginas eram feitas com float**. É o sistema mais clássico do CSS.

📌 Como funciona o float?

  • O elemento "flutua" para a esquerda ou direita
  • Permite criar colunas
  • Precisa do clear para evitar que o conteúdo suba demais
.coluna {
  width: 50%;
  float: left;
}

.clear {
  clear: both;
}

📌 Problemas do float

  • Dificuldade de centralização
  • Quebras inesperadas
  • Necessidade de clearfix
⚠️ Float **não foi criado para layouts**, mas era a única forma disponível na época.

5️⃣ Position (Sistema Antigo de Layout)

📌 position: static

Padrão. O navegador decide a posição natural.

📌 position: relative

Move o elemento sem tirá-lo do fluxo.

.box {
  position: relative;
  top: 10px;
  left: 20px;
}

📌 position: absolute

Remove o elemento do fluxo e posiciona relativo ao pai.

.popup {
  position: absolute;
  right: 0;
  top: 0;
}

📌 position: fixed

Fixa o elemento na tela.

.menu-fixo {
  position: fixed;
  bottom: 10px;
  right: 10px;
}

6️⃣ Layout com Table (muito antigo!)

Antes do Float, os sites eram construídos usando tabelas para estruturar o layout.

<table>
  <tr>
    <td>Menu</td>
    <td>Conteúdo</td>
  </tr>
</table>
❌ Hoje é **proibido** usar tabelas para layout. ✔️ Use apenas para dados.
