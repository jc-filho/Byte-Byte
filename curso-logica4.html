🔀 Estruturas Condicionais

Permitem que o programa tome decisões com base em condições.

Estruturas Condicionais

As condições servem para que o programa execute diferentes ações dependendo de uma situação.

Estrutura SE...ENTÃO

Executa um bloco de código apenas se a condição for verdadeira:

ALGORITMO "Verificar Idade" INÍCIO ESCREVER "Digite sua idade: " LER idade SE idade >= 18 ENTÃO ESCREVER "Você é maior de idade" FIM SE FIM

SE...ENTÃO...SENÃO

Executa um bloco se a condição for verdadeira, outro se for falsa:

ALGORITMO "Verificar Nota" INÍCIO ESCREVER "Digite sua nota: " LER nota SE nota >= 7 ENTÃO ESCREVER "Aprovado!" SENÃO ESCREVER "Reprovado!" FIM SE FIM

SE...SENÃO SE...SENÃO

Permite várias verificações:

ALGORITMO "Conceito da Nota" INÍCIO ESCREVER "Digite sua nota: " LER nota SE nota >= 9 ENTÃO ESCREVER "Conceito A" SENÃO SE nota >= 7 ENTÃO ESCREVER "Conceito B" SENÃO SE nota >= 5 ENTÃO ESCREVER "Conceito C" SENÃO ESCREVER "Conceito D" FIM SE FIM
