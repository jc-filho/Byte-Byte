Listas em HTML

As listas são usadas para organizar informações, agrupar itens e estruturar conteúdos em tópicos. Em HTML, existem três tipos principais de listas:

  • Listas não ordenadas – <ul>
  • Listas ordenadas – <ol>
  • Listas de descrição – <dl>

1. Listas Não Ordenadas (<ul>)

Esse tipo de lista mostra os itens com marcadores (bolinhas).

<ul>
  <li>Pão</li>
  <li>Leite</li>
  <li>Ovos</li>
</ul>
💡 Dica: Você pode mudar o estilo da bolinha com CSS usando list-style-type.

2. Listas Ordenadas (<ol>)

Nelas, os itens são numerados automaticamente.

<ol>
  <li>Ligar o computador</li>
  <li>Abrir o navegador</li>
  <li>Acessar o Byte&Byte</li>
</ol>

Tipos de numeração

Você pode mudar os números usando o atributo type:

  • 1 – números (padrão)
  • A – letras maiúsculas
  • a – letras minúsculas
  • I – algarismos romanos maiúsculos
  • i – algarismos romanos minúsculos
<ol type="A">
  <li>Item A</li>
  <li>Item B</li>
</ol>

3. Lista de Descrição (<dl>)

Usada para criar listas com termos e descrições.

<dl>
  <dt>HTML</dt>
  <dd>Linguagem de marcação para páginas web.</dd>

  <dt>CSS</dt>
  <dd>Folhas de estilo para design.</dd>
</dl>

Listas Aninhadas

Você pode colocar uma lista dentro da outra.

<ul>
  <li>Frutas
    <ul>
      <li>Maçã</li>
      <li>Banana</li>
    </ul>
  </li>
</ul>

Quando usar cada tipo?

✔ Usar <ul>: listas gerais, itens sem ordem.

✔ Usar <ol>: receitas, tutoriais, passos.

✔ Usar <dl>: glossários, definições, FAQ.
